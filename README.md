# The Right Hand Program: Concept Landing Page

A concept landing page for Kasim Aslam's Right Hand Program (Pareto Talent), built as a Pareto Talent Bootcamp project by Federico Farina.

- **Offer & copy:** Hormozi Grand Slam Offer, written in Kasim's voice
- **Brand:** Pareto Talent palette (white, ink #0B1215, emerald #10B981), Space Grotesk + Work Sans, Lucide icons
- **Build:** a single static `index.html` with no build step. It has scroll reveals, parallax, an interactive ROI calculator and CTA hover effects, and it respects reduced-motion.

## Deploy
This is a static site, so any static host works.

- **Vercel:** import this repo, set Framework Preset to "Other", and deploy.
- **Vercel CLI:** run `npx vercel --prod` from this folder.
- **Netlify:** drag the folder onto app.netlify.com/drop.

*Concept work, not an official Pareto Talent page.*
